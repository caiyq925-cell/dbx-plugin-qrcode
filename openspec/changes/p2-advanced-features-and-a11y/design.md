## Context

P0/P1 建立了双栏布局基线与防呆/导出能力。本 change 收尾三类工作：机器级扫码自检（内联解码器，单文件体积的最大增量）、两个场景功能（Wi-Fi 卡、批量出码）、工程与包容性欠账（快捷键、a11y、隐私提示）。约束不变：自包含、无网络、权限仅 `host.storage`、双语双主题。

## Goals / Non-Goals

**Goals:**
- 扫码风险从「人肉验证」升级为「机器自检 + 徽标」
- 补齐贴墙 Wi-Fi 卡与多行批量两个真实场景
- 全键盘可用、敏感内容有知情提示

**Non-Goals:**
- 不做逐码保存的批量下载（沙箱限制，明确以合并长图替代）
- 不做会话恢复/草稿（用户已确认：历史记录点击自动填充已覆盖复用诉求）
- 不做自动上报/统计（无网络权限）
- 不重构历史/预设存储结构（仅新增 `batchLimit` key）

## Decisions

1. **解码器选 jsQR（Apache-2.0；原记录为 MIT，实施时按上游 LICENSE 勘误），内联并保留版权头，只在预览分辨率（480px）单次解码**
   开发期已用 jsQR 验证过解码行为（pad≤0.08 可扫），技术栈零新知。体积：esbuild 压缩后 130KB（gzip ≈46KB），以 `type="text/plain"` 惰性块加载，首次生成前不产生解析成本；gzip 增量实测超出本条最初预估（约 20KB），待用户确认接受。备选 zxing 体积数倍且无收益。不引入 Worker（沙箱 iframe 环境 Worker 支持不确定），480px 单帧解码在低端机约 <50ms，防抖后仅执行一次，主线程可接受。

2. **自检失败级联对比度检查的提示文案**
   失败原因不尝试精确归因（解码器不输出原因），提示按启发式排序：对比度低（P1 已有检测）→ Logo 比例 >25% → 码点形状间隙；避免过度承诺。徽标是布尔结果 + 建议列表，不是诊断报告。

3. **Wi-Fi 分享卡 = 离屏 canvas 独立合成函数，不复用预览管线**
   `composeWifiCard(payload, style, locale)` 返回 canvas；卡片版式固定（上 SSID/密码、中二维码、下提示语），与预览渲染解耦，避免卡片改动影响主渲染。首次导出用既有确认弹窗告知明文密码，确认状态记入会话内存（不持久化，每次打开插件首次导出仍提醒一次，安全优先）。

4. **批量模式 = 文本页签的平行状态机，行数上限默认 10、可调最高 50（已确认）**
   `batchText` 与单条 `textContent` 独立暂存（切模式互不覆盖）；上限设置持久化到 `batchLimit` key。网格用轻量 DOM（每个码一个小 canvas）；超过上限截断并提示。合并长图列数自适应（≤2 码 1 列、≤8 码 2 列、其余最多 4 列），每码下方绘制序号与 40 字符摘要；批量数 >30 时单码自动降为 384px 控制画布内存。逐码保存明确不做（沙箱无法连续弹宿主对话框）。

5. **a11y 逐项小改，不引入焦点陷阱库**
   弹窗：打开时 `focus()` 取消按钮、keydown 监听 `Escape`、关闭时还原 `document.activeElement` 快照。页签：`roving tabindex` + 左右方向键（W3C ARIA tabs 模式的最小实现）。Toast：`role="status"`。两处硬编码 `aria-label` 改走 `applyLocale()`。

6. **Ctrl+S 在 iframe `document` 级监听，`preventDefault()` 后调用与保存按钮同一个 handler**
   宿主快捷键冲突风险低（iframe 内按键宿主不一定收到），若实测宿主拦截则降级为 `Alt+S` 并在按钮 tooltip 标注。

## Risks / Trade-offs

- [内联解码器使单文件增大约 20KB，低端机首解析变慢] → 解码器脚本置于文件尾部、初始化惰性（首次生成后 200ms 再加载执行）；实测 1024 行内文件总解析耗时
- [批量上限调至 50 码时合并长图内存峰值高] → >30 码时单码降为 384px（4 列约 2048×7600，约 62MB 峰值）；仍超出低端机承受则引导用户分批（上限本身可调回小值）
- [批量模式与单条模式状态互切易出 bug] → 两套输入独立暂存 + 切换时 `scheduleGenerate(0)` 全量重算；tasks 中列为专项回归项
- [Ctrl+S 与宿主快捷键冲突] → 实测宿主行为，冲突则换 `Alt+S`

## Migration Plan

随版本发布；新增 `batchLimit`，无 schema 变更，旧数据兼容。回滚 = 回退插件包。jsQR 版权头随内联代码保留，满足 MIT 再分发要求。
