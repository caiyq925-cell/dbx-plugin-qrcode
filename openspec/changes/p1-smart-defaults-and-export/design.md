## Context

P0 已确立双栏布局与统一校验的 UI 基线。本 change 在其上叠加五个纯前端增强，全部落在 `ui/index.html` 应用层：输入监听（URL 补全）、样式盒（预设）、导出按钮（SVG/文件名/复制尺寸）。约束不变：自包含单文件、无网络、权限仅 `host.storage`、双语言双主题。

## Goals / Non-Goals

**Goals:**
- 防呆：裸域名、低对比两类「发出去才发现」的事故在生成阶段拦截
- 复用：样式可按名保存/套用，与历史（内容+样式）解耦
- 导出：矢量格式、语义文件名、复制尺寸跟随

**Non-Goals:**
- 机器级扫码自检（内联解码器，属 P2）
- Wi-Fi 分享卡、批量出码、会话恢复（P2）
- 不改历史记录触发机制与数据结构

## Decisions

1. **URL 识别用保守启发式，不用正则穷举 TLD**
   判定：`/^[a-z0-9][a-z0-9.-]*\.[a-z]{2,}(\/\S*)?$/i` 且无空格、非 IP 纯数字场景误报可接受（`192.168.1.1` 会命中建议——但补全后 `https://192.168.1.1` 仍是合法语义，可接受；含空格一律不提示）。备选维护 TLD 列表体积大且过时。忽略记忆按内容 hash 存会话内存（不持久化——重开会话重新提示是可接受的低频打扰，避免新增存储语义）。

2. **对比度用 WCAG 相对亮度公式，阈值 3:1，透明背景按白色底估算**
   与渲染层「透明背景实际大多铺在浅色上」的假设一致；二维码模块对比是图形对比，3:1（WCAG 图形标准）比 4.5:1（正文标准）更合适。警示条独立于既有 `#error` 容器新增 `#warn`，避免与超容错误互斥逻辑纠缠。

3. **预设独立存储 `presets` key，不复用历史条目结构**
   预设 = `{ id, name, style }`，历史 = `{ id, kind, title, content, style, at }`。二者生命周期不同（预设显式管理、历史滚动淘汰）。上限 8 个防止 storage 膨胀（Logo data URL 已压缩到 96px，单个预设含 Logo 约 10-20KB，8 个安全）。无 `host.storage` 时隐藏入口而非 localStorage 降级——预设是低频功能，降级会产生「历史在 localStorage、预设也在 localStorage」的双份语义，不值得。

4. **SVG 序列化器与 `renderQr` 同源改写，不引入 svg 库**
   `renderQr` 的绘制原语只有三种：`fillRect`（方块）、`roundRect+fill`（圆角/眼睛/Logo 底衬）、`arc+fill`（圆点）。逐一映射为 `<rect>`/`<rect rx>`/`<circle>`，坐标同公式（`(x + margin + pad/2) * cell`）。Logo 用 `<image href="data:...">`。产物经 `XMLSerializer` 或字符串拼接产出。备选 `canvas.toSVG` 类库体积大且与自绘形状不兼容。风险最大的圆角眼睛几何必须与 Canvas `roundRect` 参数逐一对齐。

5. **文件名生成器独立函数 `suggestFileName(payload, kind, ext)`，非法字符统一 `_` 替换**
   URL 用 `new URL()` 解析取 `hostname`（失败则回退通用名）；域名+首段路径截断 40 字符；WiFi/vCard 复用既有 `historyMetaFor` 的标题提取逻辑，避免两套解析。

6. **复制图片尺寸跟随：复用 `exportCanvas($("px").value)`，无新增状态**
   导出与复制共用同一条「编码 → 渲染」管线，只把硬编码 512 换成选择器值。

## Risks / Trade-offs

- [SVG 与 Canvas 渲染偏差导致「看着一样、扫不出来」] → 用现有 jsQR 解码测试方法对三种形状 × 透明 × Logo 矩阵做 SVG 光栅化解码回归
- [URL 误报建议条打扰纯文本用户] → 「保持纯文本」一键忽略 + 同内容会话内不再提示；保守正则宁漏勿误
- [预设含 Logo 的 data URL 占用 storage 配额] → Logo 已在选图时压到 96px；保存预设时复用同一份压缩 data URL，不二次放大
- [文件名语义化与用户手动改名的宿主保存对话框冲突] → 语义名只是初始建议，宿主对话框内仍可改名，无锁定

## Migration Plan

随插件版本发布，无数据迁移；`presets` 为新增 key，旧版本数据不受影响。回滚 = 回退插件包，历史不受影响。

## Open Questions

- SVG 是否需要同时提供「含白色底衬的安全区」变体（印刷场景常要求静区留白）——倾向暂不做，透明背景 + 留白滑杆已覆盖
