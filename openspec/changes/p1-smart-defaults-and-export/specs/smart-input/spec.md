## ADDED Requirements

### Requirement: 裸域名识别与补全建议
当文本页签内容形似域名（含点号、无空格、非纯数字/标点）且不带 `scheme://` 前缀时，系统 SHALL 在输入区下方显示补全建议条「按网址处理，补全 https://？」，并提供「保持纯文本」忽略选项。

#### Scenario: 粘贴裸域名出现建议条
- **WHEN** 用户在文本页签粘贴 `github.com/t8y2/dbx`
- **THEN** 输入区下方出现补全建议条，二维码暂保持文本编码不变

#### Scenario: 不误伤正常文本
- **WHEN** 用户输入 `你好世界` 或 `192.168.1.1 网关地址`（含空格或明显非域名）
- **THEN** 不出现补全建议条

### Requirement: 一键补全并重新生成
用户点击建议条后，系统 SHALL 将输入替换为 `https://` + 原文并立即重新生成二维码，且对同一条内容不再重复提示。

#### Scenario: 点击补全
- **WHEN** 建议条可见且用户点击「补全 https://」
- **THEN** 输入框内容变为 `https://github.com/t8y2/dbx` 并重新生成
- **AND** 该条内容再次粘贴或编辑回来时不再重复弹建议

#### Scenario: 忽略建议
- **WHEN** 用户点击「保持纯文本」
- **THEN** 建议条消失、输入不变、二维码保持文本编码，且同一条内容不再提示

### Requirement: 建议条不干扰历史与生成
补全建议仅为输入层辅助：无论建议条是否可见，实时生成、历史记录（显式保存后写入）SHALL 按当前实际输入正常工作。

#### Scenario: 忽略建议时保存
- **WHEN** 用户忽略建议条后点击「保存 PNG」
- **THEN** 保存的是文本编码的二维码，历史记录内容与实际输入一致
